== Description ==

BlogWings is a fast, modern data-journalism theme for tracking the WordPress ecosystem. It ships with a glassy sticky header with mega menus, a search overlay, dark mode, a rich footer and full-width layouts.

It is designed to pair with the BWing plugin (rankings, statistics, theme detector and dashboard), but works great as a blog theme on its own.

= Features =

* Glassy sticky header with dropdowns and optional mega menus (add the class `bw-mega bw-mega--theme`, `bw-mega--plugin` or `bw-mega--author` to a top-level menu item for a live "Top right now" panel when BWing is active).
* Search overlay (uses BWing live search when available, the standard search form otherwise).
* Light / dark mode with a visitor toggle and a configurable default (light, dark or follow the visitor's device).
* Customizer panel "BlogWings options": brand and accent colours, container width, header badge and button, sticky header, search button, footer about text, social links, newsletter, copyright, blog sidebar, blog heading and intro.
* Full width page template (pages and posts).
* Breadcrumbs, reading time, post meta and pagination.
* Block editor support: wide/full alignment, editor styles, block styles, responsive embeds and a custom colour palette.
* Two menu locations (Primary, Footer) and two widget areas (Blog sidebar, Footer column).
* Custom logo, featured images, threaded comments and translation ready.
* Accessible: skip link, keyboard-friendly dropdowns and search dialog.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme, choose the theme ZIP file and click Install Now.
3. Click Activate to use your new theme right away.
4. (Optional) Install and activate the BWing plugin to unlock rankings, statistics, the theme detector and the home page sections.
5. Go to Appearance > Customize > BlogWings options to configure the theme.

== Frequently Asked Questions ==

= Does the theme require the BWing plugin? =

No. BlogWings works as a regular blog theme. The BWing plugin adds rankings, statistics, the theme detector, live search and the home page sections.

= How do I set the default colour mode? =

Go to Appearance > Customize > BlogWings options > Colours & layout and choose Light, Dark or Follow visitor's device. A visitor's own toggle choice overrides the default.
